Where and How is LangGraph Used?

Unlike traditional linear LLM chains that execute in a single direction (Input → Prompt → Output), LangGraph enables cyclical state machine orchestration with checkpoint persistence:

  • StateGraph & Typed State: Explicitly threads candidate code, test execution stderr, assertion results, and retry counters across isolated worker nodes.
  • Cyclic Conditional Edges: Evaluates sandbox results. If tests fail, it routes control back to the debug_repair_node to patch the bug, which loops back into the sandbox_node for re-testing.
  • Subprocess Sandboxing: Safely runs generated code with timeout bounds to protect against infinite loops or resource exhaustion.
  • State Checkpointing (MemorySaver): Snapshots every state transition so the entire diagnosis and repair trajectory is recorded and inspectable.
